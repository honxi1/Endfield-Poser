# 使用须知

> 面向玩家的必读清单。完整图文流程见《使用教程.md》（仓库里是 `docs/tutorial.md`）；
> 条款全文见仓库 README 的「用户协议与免责声明」。

## 这是什么

《明日方舟：终末地》的游戏内摆姿插件：让角色停在当前姿态，用鼠标点骨骼、拖旋转盘摆姿势，
可保存 / 载入姿态预设。只在**单人 / 摄影模式**下使用。

## 用之前

1. 用**官方启动器**或 **XXMI** 启动游戏；不要直接双击游戏主程序（那样插件加载不上）。
2. 游戏请用「窗口化」或「无边框全屏」；独占全屏会让面板看不见。
3. 第一次进游戏会弹出「用户协议与免责声明」：把条款滚到底 → 点「同意并继续」。
   如果点不到按钮，**按住 `Alt`** 呼出游戏光标再点。同意之后，面板顶部的「用户协议」
   按钮可以随时打开回看（只读窗口，点「关闭」返回）。

## 基本操作

| 操作 | 说明 |
|---|---|
| `L` | 呼出 / 隐藏面板 |
| `P` | 冻结 / 解冻 |
| 按住 `Alt` | 把光标交给面板（游戏平时锁住鼠标转视角） |
| 面板「快捷键（可改）」 | 改键；建议带 `Ctrl`，避免游戏内打字误触发 |

用法：冻结 → 点选骨骼（勾「全量骨骼」可点到手指等细节）→ 拖旋转盘或填参数 → 命名保存。

## 文件在哪

- 姿态预设：`游戏目录\plugin\poses`
- 日志：`游戏目录\plugin\poser_log.txt`（面板顶部有「打开日志」按钮）

## 请遵守

- 只在**单人 / 摄影模式**使用；不要用于多人联机、竞技或会影响他人的场景。
- 不要利用本插件或游戏内的官方素材，制作、播放、传播任何不合适的动作 / 动画。
- 不要修改或传播付费内容与游戏资源；姿态文件只保存你自己摆出的骨骼数据。
- 这是非官方第三方工具，与游戏厂商无关；使用它**可能违反游戏服务条款**，账号风险请自行
  评估，建议先用小号 / 测试账号体验。

## 出问题怎么反馈

把 `plugin\poser_log.txt` 和复现步骤一起发到 issue 或交流群（面板顶部「打开日志」能直接定位文件）。

## 怎么卸载

用包里的 `安全安装.bat` 卸载；或手动删除 `plugin\poser.dll`、`plugin\poser_config.txt`
与游戏根目录的两个代理 DLL，并还原安装时备份的文件。
