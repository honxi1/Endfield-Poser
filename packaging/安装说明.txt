Endfield Poser v0.3.8 —— 安装与使用
=====================================

【这个包是什么】
《明日方舟：终末地》的游戏内摆姿插件（独立仓库，依赖全部自包含）。
功能：角色冻结、3D 点选骨骼 + 旋转盘、旋转/位置参数（滑条 / 数值输入 / ± 步进 / 复位）、
      姿态预设保存与载入（含从骨）、WebUI、SMC 表情面板、多角色分别摆姿。

完整图文流程见包内【使用教程.md】（安装 → 首次启动 → 冻结 → 摆姿 → 表情 → 姿态库 → 排错）。
先看简洁版的话，见包内【使用须知.md】。

【第一次启动：用户协议弹窗】
第一次进游戏时，屏幕中央会弹出「用户协议与免责声明」。需要把条款滚到底，
「同意并继续」才会变成可点。**在点同意之前，插件不会安装任何游戏侧 hook、
也不会读写游戏数据**（日志里停在 [LEGAL] waiting for the user to accept the terms...）。

- 点不到按钮？**按住 Alt 呼出游戏光标**（游戏平时把鼠标锁起来转视角），然后再点。
  弹窗里也会显示一行提示告诉你当前是哪种情况。
- 点「同意并继续」：往 plugin\poser_config.txt 写一行 terms_version，以后不再打扰；
  条款版本更新时会再弹一次。
- 点「不同意（本次不加载）」：本次不加载任何功能。之后按面板快捷键（默认 L）可以把窗口
  叫回来，不必重启游戏；日志里会写 [LEGAL] terms declined; plugin stays inert。
- 同意之后再想看条款：面板顶部有「用户协议」按钮，随时可以打开回看（只读窗口，点「关闭」返回）。

【懒人安装】直接双击包里的 安全安装.bat，按提示把游戏根目录拖进窗口即可
          （它会备份原版 d3dcompiler_47.dll / vulkan-1.dll；卸载时还原，
           且不会删除你的 plugin\poses 姿态预设与配置）。
          ⚠ 注意：向导**不会覆盖你已有的 plugin\poser_config.txt**（防止重置你自定的热键）。
          老用户升级后热键由插件自己迁移一次（见下）。

【手动安装】
1) 备份游戏目录原有的 d3dcompiler_47.dll 与 vulkan-1.dll；
2) 把本包里的 d3dcompiler_47.dll 与 vulkan-1.dll 都复制到游戏根目录（覆盖游戏自带的）；
   （DX11 只用 d3dcompiler_47.dll，Vulkan 只用 vulkan-1.dll；两个一起放互不影响，
     不确定游戏用哪种渲染时，一起放最省事）；
3) 新建/确认游戏根目录下有 plugin\ 文件夹（注意是单数 plugin，不是游戏自带的 plugins\），
   把 plugin\poser.dll 与 plugin\poser_config.txt 放进去；
4) 用【官方启动器或 XXMI】启动游戏。

【启动方式】请用官方启动器（Hypergryph Launcher）或 XXMI 启动，两种都实测可用。
不要直接双击 Endfield.exe：那条路径会跳过官方初始化流程，早期版本还会在 IL2CPP
就绪前 attach 而触发 Unity GC 致命错误（弹窗：Threads explicit registering is not
previously enabled / Collecting from unknown thread，同时写进游戏根目录的 Endfield.gc.log）。
现在插件会等运行时就绪再接入、超时就安静不加载，不再把游戏带崩，但直启仍不推荐。

【热键】
  L     呼出 / 隐藏面板   （gui_toggle_key）
  P     冻结 / 解冻       （freeze_key）
默认用 L / P 是为了不和其它插件抢按键；在游戏里打字会误触发时，建议改成带 Ctrl 的组合。
改键：主面板顶部 `快捷键（可改）` → 点 `改键` → 直接按你想用的键（自动写回配置，Esc 取消）。
主面板顶部会显示**当前实际生效**的两个键。

【排错：把日志发给我】
主面板顶部有 **「打开日志」** 按钮：点了会自动弹出资源管理器并选中
<游戏根目录>\plugin\poser_log.txt，把这个文件拖给作者即可。

【使用】
面板交互：按住 Alt（或游戏自己放开光标，例如摄影模式）时，鼠标归面板；
          其余时间鼠标键盘完全归游戏。点击输入框可直接打字（失焦后键盘立刻还给游戏）。

摆姿：冻结后 3D 点选骨骼 → 拖旋转盘 / 调参数。取消选中：点 3D 视图的**空白处**
      （在远处空白处单击即可；按住拖动是转镜头，不会误取消）。

多角色：冻结状态按角色记忆——切到没冻过的角色时它保持默认（正常活动），
        切回冻过的角色会恢复你离开时的姿势；后台已冻结角色会一直保持摆好的样子。
        注意只有"当前角色"可编辑，要改别的角色先切过去。

表情：滑条值恒为"相对中性默认脸"的权重（默认脸自动采样，等价于面部的 A-pose）；
      冻结会保持当前表情；「全部归零」回到默认脸；「读入当前表情」把游戏当前表情读进滑条。

姿态保存位置：<游戏根目录>\plugin\poses\*.poser.json
日志：<游戏根目录>\plugin\poser_log.txt（排查问题先看这里）

【本版新增（v0.3.8）】
- **窗口布局记忆**：各窗口的位置 / 尺寸会自动记住（写到 plugin\poser_ui.ini），
  拖到哪下次还是哪；主面板「重置窗口」一键回到默认布局。
- **窗口开关集中**：主面板新增「窗口」组，统一开关骨骼参数 / 姿态库 / 形态键 /
  角色列表四个窗口，勾选状态写回配置。
- **人物位置（Root XYZ）** 从主面板挪到「骨骼参数」窗口，和选中骨参数归在一起。
- 移除「图钉」：窗口直接拖标题栏就能移动，不用先解锁。
- 稳定性：加固启动时的 IL2CPP 接入时机，减少刚进游戏就报 GC 致命错误的情况。
- 致谢：感谢 White-NX（XXMI/3DMigoto 兼容的 overlay）与 Nordlicht S（安全安装 / 卸载脚本）。

【已知问题】
- **冻结后骨架有轻微颤抖**（老机制遗留：逐帧钉姿势会和游戏侧仍在写的系统轻微打架，
  表现为在静止姿态与当前摆姿之间来回）。不影响摆姿与保存，本版未修；
- 某些特殊场景（例如不能切换角色的剧情/试用场景）插件可能抓不到角色
  （日志里 `Re-capture retry: animator=0`），此时无法摆姿；后续会加"扫描场上 Humanoid Animator"的捕获路径；
- **从骨（飘带 / 裙摆 / 头发）的冻结还没适配多角色**：切编辑目标后飘带等从骨的
  冻结状态可能不跟随（本版已知，下一版处理）；
- 表情（SMC 权重）不写入姿态文件，也不能跨角色通用，请在新角色上重调；
- 表情滑条只覆盖游戏自带的 5 个口型 + 19 个表情，其它 morph 表示不了（但会被内部基准保住）；
- 角色列表只在"场上有多个角色"时才有意义（摄影模式等）；列表是**按需刷新**的，
  场上人员变化后点一次「刷新列表」；
- 相机参数不随姿态文件保存；
- 默认键 L / P 是单个字母：游戏内文本框/聊天里打字时可能误触发（插件自己面板的
  输入框已屏蔽）；觉得碍事就在「快捷键（可改）」里换成带 Ctrl 的组合；
- **四肢 IK 控制器仍是实验性功能**（默认关闭，面板里勾选开启）：能选中 / 拖动手柄并
  写回骨骼，但限位、手感与躯干联动还在打磨；
- 骨骼层级树、撤销/重做、骨骼镜像未包含在本版。
