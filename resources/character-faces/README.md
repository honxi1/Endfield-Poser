# 角色表情校准

37 份校准覆盖 35 个角色标识，包含左右眼、眉毛、口型等映射。文件不包含模型网格、贴图或动作。

MMD 表情参考自[茶叶味香皂](https://space.bilibili.com/3546783156276148)制作的《明日方舟：终末地》MMD 模型。模型及游戏资产的权利归各自权利人所有，相关素材请遵守原作者的使用规则。

构建、打包时自动复制本目录的 `*.face.json`；安装后位于 `plugin/mmd/character-faces/`。更新会覆盖同名内置校准，自行修改前请备份。其他自定义文件及姿态不会被删除。

校准在插件启动时读取，按角色和面部骨架匹配。缺失或不适用的表情可用固定映射补充；材质、贴图等特殊效果不在支持范围内。
